# HiGestio Caja

El programa de la caja de [HiGestio](https://higestio.com) para el computador del local: solo para vender, con y sin internet.

Este repositorio guarda solo los instaladores. Se descargan desde [higestio.com/descargar](https://higestio.com/descargar) o desde [la última versión](https://github.com/HiGestioSaaS/higestio-caja/releases/latest):

- Windows 10 u 11: `HiGestio-Caja.exe`
- Mac (Intel y Apple Silicon), macOS 12 o más nuevo: `HiGestio-Caja.dmg`

Se entra con el mismo negocio, usuario y clave de HiGestio. La pantalla se carga desde higestio.com, así que cada arreglo llega solo al abrir el programa.

Todavía no está firmado. Al abrirlo por primera vez:

- En Windows aparece "Windows protegió su PC": toca **Más información** y **Ejecutar de todas formas**.
- En el Mac, si no abre: **Ajustes del Sistema**, **Privacidad y seguridad**, **Abrir igualmente**.
